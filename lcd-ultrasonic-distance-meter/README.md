# LCD Ultrasonic Distance Meter

An Arduino-based distance meter that measures the distance to an object using an HC-SR04 ultrasonic sensor and displays the result on a 16×2 LCD.

## How It Works

The sensor sends an ultrasonic pulse and measures the time taken for its echo to return. The Arduino calculates the distance in centimeters and updates the LCD every 500 milliseconds.

## What I Used

- Arduino Uno
- HC-SR04 ultrasonic sensor
- 16×2 LCD
- Breadboard and jumper wires

## What I Learned

- Measuring distance using ultrasonic pulse timing
- Converting echo duration into distance using the speed of sound
- Integrating an ultrasonic sensor with a 16×2 LCD
- Improving display readability and measurement stability
