# Smart Parking Assistant

An Arduino-based parking assistant that uses an ultrasonic sensor, LCD, RGB LED, and buzzer to help indicate the distance from an obstacle.

## How It Works

The HC-SR04 measures the distance to an obstacle. The LCD displays the distance and parking status, while the RGB LED changes color and the buzzer sounds to indicate how close the obstacle is.

## What I Used

- Arduino Uno
- HC-SR04 ultrasonic sensor
- 16×2 LCD
- RGB LED
- Buzzer
- Breadboard and jumper wires

## What I Learned

- Using distance thresholds to create multiple parking warning levels
- Integrating an ultrasonic sensor with an LCD, RGB LED, and buzzer
- Creating custom LCD characters using a byte array
- Converting ultrasonic echo duration into distance measurements
